# Cairn Text

A lightweight text editor built with [egui](https://github.com/emilk/egui), part of the Cairn ecosystem.

## Features

- Multi-tab editing with dirty indicators
- File open/save/save-as via native dialogs
- Keyboard shortcuts (Ctrl/Cmd+S/O/T/W)
- Monospace code editing

## Run natively

```bash
cargo run --release
```

## Run in browser (WASM)

```bash
trunk serve
```
